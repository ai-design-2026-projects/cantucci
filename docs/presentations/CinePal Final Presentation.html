Fusion Strategies

Text and visual encoders inhabit different semantic spaces.

Vector-level

Movie and review embeddings are merged by a weighted average inside the same space (0.6 / 0.4).

→ Fused BGE vector · 1024-d

Distance-level

Text and trailer are fused as a weighted sum of their cosine-distance matrices (0.6 / 0.4).

→ N × N distance matrix

Architecture

Coordinator

The deterministic orchestrator: both session handler and turn-workflow manager.

  • The only writer of state and the sole component that talks to the oracle
  • Holds no in-memory session state between turns
Architecture

Intent Agent

Interprets the oracle's free-form message and emits an ordered list of actions.​

  • Low confidence: routes to the Clarifier agent
  • Explanation request: routes to the Explanation agent
  • Casual message: returns a predefined static reply​
  • Snapshot navigation: re-points in the snapshot tree​
  • Otherwise: identifies clustering operation​
Input
Message; Current Cluster Labels
Output
Ordered list of actions
Architecture

Operations Catalogue

A fixed, closed vocabulary, used by the Intent Agent.

Navigation
cluster  split into sub-groups
merge  combine clusters
focus  keep one, drop the rest
cross-filter  match a predicate
exclude  drop one cluster
reset  return to unclustered
undo  step back a snapshot
Dialogue moves
explain  why a film sits here
small-talk  non-operational reply
Architecture

Clarifier Agent

A fast-model gate that asks one disambiguating question when confidence is low.

  • Fires when any action falls below the confidence threshold
  • Asks a single disambiguating question
Input
Low-confidence action; User message; Current clusters labels
Output
One clarifying question
Architecture

Concept Agent

A model that builds a linear axis when a split is semantic rather than a deterministic partition.

  • Triggered only for concept-guided requests
  • Builds a unit vector from a positive and negative pole pair
  • The axis then scores films within the chosen space
Input
Concept string; Declared space
Output
Linear axis
Architecture

Clustering

The deterministic computational engine behind every clustering operation.

  • A pure pipeline: UMAP reduction followed by HDBSCAN
  • Returns per-film membership probabilities, not rigid hard labels
  • In multimodal mode, the distance matrix is fed to HDBSCAN
Architecture

Labeling Agent

A fast-model agent that names and summarises clusters

  • Metadata partitions: assigned deterministically
  • Semantic clusters: assigned through a LLM call
  • Anchored on the previous turn's names
  • Always generates summaries through a LLM call
Input
Exemplar films; Label context
Output
Label context; Label; Summary
Architecture

Explanation Agent

A strong-model agent that explains why a given film sits in a given cluster.

  • Grounded in the cluster's label and exemplars
  • Outputs a concise, natural-language placement rationale
Input
Cluster label; Cluster summary; Exemplars
Output
Concise explanation
Architecture

Suggestion Agent

A fast-model responder that proposes a next step once the actions complete.

  • Computes deterministic signals: a similar-cluster pair, a dominant cluster, a high noise fraction
  • May decline if it cannot identify a coherent suggestion
Input
Current cluster; Signals; Last operation
Output
Proposed next step (or none)

Appendix  ·  Ethics

Ethical Considerations

01

Synthetic oracle limits

All evaluation relies on an LLM-simulated oracle, so findings reflect agent-to-agent dynamics, not authentic human behaviour.

02

Model & embedding bias

The language and embedding models are trained predominantly on Western, English-language data, inheriting its cultural biases.

03

LLM-as-a-judge risks

Using an LLM to evaluate another introduces structural risks around accuracy, blind spots, and hallucination.

Evaluation

01

Three LLM families

02

Confidence intervals

Every reported metric carries its two-sided 95% confidence interval.

Oracle model class
