\section{Evaluation Framework}\label{sec:evaluation}

\subsection{Evaluation Design}

Because cluster quality is defined by the oracle, the system cannot be graded against a fixed target.
The evaluation instead centres on one question:
\begin{center}
\itshape
\begin{minipage}{0.82\textwidth}
\centering
Does an intent-driven navigation loop produce more coherent clusterings of the catalogue, with less oracle effort, than other variants?
\end{minipage}
\end{center}
We approach it from three angles:
\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Operation choice}: given a free-form message, does the Intent agent pick the right navigation operation and the right parameters?
  \item \textbf{Cluster update strategy}: do concept-guided splits, soft HDBSCAN memberships, and the content-addressed snapshot tree yield more stable, more separable clusters than plain re-clustering on raw embeddings?
  \item \textbf{Satisfaction}: how do we assess clustering quality when there is no recommended film list, only a sequence of cluster snapshots, and how far do those assessments generalise?
\end{itemize}

To answer this, the evaluation closes a \textbf{three-party loop}: the \textbf{system under test} is driven by an \textbf{LLM-simulated oracle} that plays a user with a hidden goal, while a separate \textbf{LLM judge} scores the finished session.
The system, oracle, and judge each run on a different model family, so that none rewards outputs matching its own conventions.

\subsection{Oracle Formulation}

\paragraph{Ground truth:} Each session is anchored by a ground truth: a target navigation \textbf{trajectory}, an ordered list of operations, paired with a natural-language \textbf{intent description} that paraphrases it.
The oracle is shown only the intent description, in order to act as a real user would.

\paragraph{Persona:} A persona is layered on top of the ground truth through two dials:
\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Verbosity} controls how much the oracle says;
  \item \textbf{Patience} controls how many misunderstandings it tolerates before giving up.
\end{itemize}

\paragraph{Protocol:} To ensure the simulated oracle aligns with the application and evaluation's interactive workflow, it adheres to a strict communication protocol.
The oracle issues exactly one request per message, explicitly answers any clarifying questions raised by the system, and requests an explanation for why a specific film resides within its cluster exactly once per session.
The session terminates organically when the oracle either achieves success, concluding with a high satisfaction rating of 4 or 5, or decides to give up after repeated system failures, yielding a low rating of 1 or 2.
Finally, a strict \textbf{turn budget} serves as a hard cap to terminate the session if neither natural exit condition is met.

\paragraph{Reproducibility:} The oracle is engineered to be fully reproducible: its output behaves as a deterministic function of the configured persona, the catalog's ground truth, the session seed, and the active turn number.
Its only source of non-determinism, the language model's sampling, is itself keyed on that same quadruple, so rerunning the exact configuration reproduces the same session rather than drifting.

\subsection{Metrics} Evaluation runs automatically at the end of each session and produces two kinds of measurement.

\paragraph{Deterministic metrics} Read directly from the recorded session state, with no model
involved:
\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Final cluster count}: number of clusters in the final snapshot;
  \item \textbf{Turns}: number of oracle turns in the session;
  \item \textbf{Operations}: number of navigation operations executed;
  \item \textbf{Clarifier trigger rate}: fraction of turns on which the clarifier fired;
  \item \textbf{Total cost}: cumulative LLM cost of the session;
  \item \textbf{Oracle rating}: the oracle's own self-rating (1--5).
\end{itemize}

\paragraph{Judge dimensions} Subjective scores (1--5) assigned by the judge after reading the full transcript, the per-turn action log, and clusters.

\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Operation appropriateness}: did the system pick the right operation and parameters for each request;
  \item \textbf{Intent alignment}: does the final result reflect the stated goal;
  \item \textbf{Label accuracy}: do the cluster names and summaries match their contents;
  \item \textbf{Clustering coherence}: do the films within each cluster genuinely belong together;
  \item \textbf{Explanation quality} (conditional): is a placement explanation faithful and specific;
  \item \textbf{Suggestion meaningfulness} (conditional): is a volunteered suggestion relevant and well-timed;
  \item \textbf{Concept-axis quality} (conditional): do the axis poles form a coherent, discriminative spectrum.
\end{itemize}

Because the conversational setting lacks a rigid ground-truth trajectory, traditional supervised alignment is impossible. 
The oracle's private plan is inherently flexible; its free-form messages are stochastic, meaning several distinct operational paths can validly satisfy the same underlying intent.
Instead, the judge evaluates appropriateness dynamically, rating whether the system's chosen operation and parameters constitute a logical and valid response.

\paragraph{Confidence Intervals} For every metric, the dashboard reports a two-sided 95\% confidence interval of the mean, computed from per-session values using a $t$-distribution:

\begin{equation}
  \text{CI}_{95} = \bar{x} \;\pm\; t_{0.975,\,n-1}\cdot \frac{s}{\sqrt{n}},
  \qquad
  s = \sqrt{\frac{1}{n-1}\sum_{i=1}^{n}\left(x_i-\bar{x}\right)^2},
  \label{eq:ci}
\end{equation}

where $n$ is the session count, $s$ is the Bessel-corrected sample standard deviation, and $t_{0.975,\,n-1}$ is the critical value for $n-1$ degrees of freedom (falling back to $1.96$ for $n \geq 31$).
Bootstrapping is deliberately avoided: at our sample sizes ($n \approx 30$ per condition), resampling cannot recover information a small sample lacks.
Non-overlapping intervals are interpreted as a practical indicator of a meaningful difference between conditions, rather than a formal hypothesis test.
