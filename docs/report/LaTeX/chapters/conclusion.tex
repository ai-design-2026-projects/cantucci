\section{Conclusion}\label{sec:conclusion}
CinePal set out to cluster a movie catalogue not against a fixed metric but through conversation, with the oracle's acceptance as the objective.
The build-heavy contribution promised in the introduction is realized: a working multi-agent conversational architecture, a reproducible multi-modal data pipeline, and an automated oracle-and-judge evaluation harness. 
Driving the full system with a simulated oracle confirms that this conversational, acceptance-driven approach is viable, with its remaining weaknesses confined to localized, fixable components rather than the core design.
