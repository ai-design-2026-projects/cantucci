# Evaluation Harness

Offline pipeline that measures CinePal's quality without a human in the loop. It replaces the human oracle with an LLM-simulated persona that converses with the live system, then scores the resulting conversation with a separate LLM judge. The only ground truth is the oracle's own satisfaction rating — there is no pre-labelled dataset to compare against.

Results are visible in the **Evaluation Lab** tab in the frontend (admin login required — see [`db/README.md`](../db/README.md) for creating an admin account).

---

## Prerequisites

```bash
python -m db.apply
CONFIG_PATH=configs/eval.yaml python -m db.ingest --set eval_holdout
```

The eval harness runs against the `eval_holdout` split — a disjoint slice of the catalogue never written to the main DB. Set `CONFIG_PATH=configs/eval.yaml` so the ingestion command reads the correct artifact path.

All knobs (oracle model, judge model, parallelism, cost limits) are in [`configs/eval.yaml`](../configs/eval.yaml).

---

## Step 1 — Build bundles

A bundle is a YAML file in `eval/personas/conf/` combining a persona (verbosity, patience, theme) with a ground-truth trajectory generated by an LLM.

**Random batch:**

```bash
python -m eval.builder --count 5
```

| Argument | Description |
|---|---|
| `--count N` | Build N bundles with freely invented themes and randomised dials |
| `--slug SLUG` | Build a single bundle with this slug (mutually exclusive with `--count`) |
| `--verbosity` | Oracle verbosity: `terse`, `medium` (default), `verbose` |
| `--patience` | Oracle patience in [0, 1] — how long before disengaging (default: `0.7`) |
| `--hint` | Optional theme hint injected into the ground-truth prompt |

**Single explicit bundle:**

```bash
python -m eval.builder --slug action_v1 --verbosity terse --patience 0.4 --hint "action films, exclude superhero"
```

Re-running the same slug raises an error — slugs are unique per file.

---

## Step 2 — Run sessions

**All bundles:**

```bash
python -m eval.run --all --run-name baseline-v1 --seeds 1 2 3
```

| Argument | Description |
|---|---|
| `--all` | Run all bundles in `eval/personas/conf/` |
| `--persona SLUG` | Single persona slug |
| `--personas SLUG …` | One or more persona slugs |
| `--run-name NAME` | Auto-creates a run row if it doesn't exist; uses the most recent if multiple share the name |
| `--run UUID` | Bind to an existing run by UUID (mutually exclusive with `--run-name`) |
| `--seeds INT …` | One or more RNG seeds — each seed spawns one session per persona |
| `--condition` | `conversational` (default) or `baseline` |
| `--evaluate-only UUID` | Re-score an existing conversation — skips simulation entirely |
| `--ground-truth SLUG` | Ground-truth slug passed to the judge when using `--evaluate-only` |

Sessions run in parallel (bounded by `runner.max_parallel` in `configs/eval.yaml`).

---

## Session termination

| Status | Meaning |
|---|---|
| `finished_trajectory` | Oracle satisfied (`oracle_rating ≥ 4`) |
| `finished_misbehaviour` | Oracle dissatisfied (`oracle_rating < 4`) |
| `finished_budget` | Turn budget exhausted (`runner.max_turns` reached) |

## Directory layout

```
eval/
├── run.py                CLI — run sessions (python -m eval.run)
├── config.py             configs/eval.yaml loader (eval_harness: section only)
├── logging_setup.py      eval-specific log configuration
├── types.py              Canonical operation vocabulary (NAVIGATION_OPERATIONS, OpSpec, PERSONAS_DIR)
├── builder/              Bundle builder
│   ├── __main__.py       CLI — build bundles (python -m eval.builder)
│   ├── builder.py        build_bundle() / build_random_batch()
│   ├── types.py          GroundTruthProposal, OpProposal (pydantic wire)
│   └── prompts/
│       └── ground_truth_v3.j2
├── personas/             Bundle store
│   ├── conf/             Bundle YAML files (generated artifacts — gitignored)
│   ├── store.py          File I/O + idempotent DB upsert
│   └── types.py          PersonaBundle dataclass
├── runtime/              Session driver internals
│   ├── session.py        run_simulated_session()
│   ├── batch.py          run_personas() / run_all_personas() — parallel + Rich progress
│   ├── evaluate.py       evaluate_conversation() — judge scoring
│   ├── handlers.py       select_handler() + system-under-test adapters
│   ├── termination.py    infer_termination_status()
│   └── snapshot.py       build_cluster_info() — shared by session and judge
├── oracle/
│   ├── agent.py          oracle_turn() — intent-driven, no to-do list
│   ├── types.py          OracleLLMResponse, OracleTurnResult
│   └── prompts/oracle_v7.j2
└── judge/
    ├── agent.py          judge_conversation() — single LLM call
    ├── types.py          JudgeLLMResponse, JudgeResult
    └── prompts/judge_v5.j2
```

SQL schema lives in `db/migrations/012_evaluation.sql`. Data access is in `backend/data_access/eval/queries.py`.
